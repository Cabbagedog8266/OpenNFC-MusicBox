一、PCB 天线设计

1自定义天线设计

板上预留了 R0 位置，方便你设计符合自身需求的 PCB 天线：只需把 R0 的封装替换成自己的天线设计即可。

⚠️ 注意 这一步会产生可忽略的 DRC 报错，属正常现象，无需处理。

2Pro Antenna Designer 线圈设计

用 Pro Antenna Designer 设计的线圈默认使用插件焊盘，同样会带来可忽略的 DRC 报错。

3谐振校准说明

  • 谐振状态的微小偏差对性能影响约 0.05 dB，可忽略不计。
  • 无专业测试仪器时，可直接使用 Designer 给出的 LC 匹配规格参数。
  • 为保证带宽与能量，建议 Q 值 ≈ 20，且不要超过 20。

4布局注意事项

线圈外围 5 mm 范围内（含上下两面）请避免放置焊盘或其他金属走线，以免影响天线性能。

⚠️ 重要 天线周围务必保持净空，金属会显著劣化天线性能。

三、音频文件转换指南

按你手头已有的素材，选一种方式：

情况做法
1️⃣ 已有乐谱 编辑 code/Core/Src/music_data.c 的旋律数组，并同步修改 code/Core/Inc/music_data.h 的 MUSIC_LEN
2️⃣ 有单音轨 MIDI、无旋律 txt 用 prts.online 提取旋律，选「保留最高音」；网站还提供 Viterbi 解码与 YIN 自相关算法
3️⃣ 什么都没有 安装 MelodyExtractor_Setup_v1.0.0.exe 提取旋律后手动编辑；源码见 GitHub
💡 旋律数据格式 music_score[] 里每项是一个音符 {频率, 时长}，单位 {Hz, ms}；频率填 0 表示休止符。改完记得把 music_data.h 里的 MUSIC_LEN 改成数组实际长度。
